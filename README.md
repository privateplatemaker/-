# Private Plate Maker

A luxury, animated, SEO-optimised landing page targeting the keyword **number plates maker**.

## Files
- `index.html` - main page (1000+ word article, headings, inline SVG images, animations)
- `robots.txt` - crawler rules and sitemap location
- `sitemap.xml` - sitemap for search engines
- `README.md` - this file

## Setup
1. Replace `https://privateplatemaker.com/` with your real domain in `index.html` (canonical), `robots.txt` and `sitemap.xml`.
2. Upload all files to the site root.
3. Submit `sitemap.xml` in Google Search Console.

## Notes
- No phone number or call button is included.
- Plate images are inline SVG; you can swap them for real photos using `<img>` tags with descriptive alt text.
